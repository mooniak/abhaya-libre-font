The pre-1978 letter forms, shown with the traditional-orthography stylistic set (ss09) turned on. Without it the same text sets in the modern forms (see the Tamil alphabet). A font that has no traditional forms shows the modern ones here.

## ா on ண ன ற

ணா னா றா

மணாளன் வானம் மீனா இறால் கறார் பாறை

## ை on ண ன ல ள

ணை னை லை ளை

கணை இணை மனைவி நினைவு இலை தலை வளையல் களை

## ொ and ோ on ண ன ற

ணொ ணோ னொ னோ றொ றோ

பொன்னோடு கணோடு றோஜா

## The alternate ர

ர் ரி ரீ — பார்த்தான் சரி கரீம்

## In running text

தலைவன் மனைவியுடன் வானம் பார்த்தான். இலை மேல் பனி; வளையல் ஒலித்தது. மணாளன் நினைவில் களைப்பு மறந்தது.
